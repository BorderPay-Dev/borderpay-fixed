## Conformance Rules
- Only official provider documentation is used.
- If a detail is not explicit in the referenced docs, status is `Requires clarification`.
- No inferred behavior is treated as supported.

## BorderPay Product Contract (Doc-Conformant)
- `Receive` -> Provider rail -> Wallet credit.
- `FX` -> **Bridge only** -> Wallet -> Wallet, constrained to documented executable pairs.
- `Send` -> Wallet -> External destination:
  - Bank / External account rails (Bridge and/or Flutterwave by corridor policy),
  - Stablecoin / crypto address rails where documented and enabled,
  - Mobile Money via Flutterwave where documented and account-enabled.
